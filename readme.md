✅ To-Do List Application

📌 Project Overview

The To-Do List Application is a simple task management web application developed using Python and Streamlit. It helps users organize their daily activities, manage tasks, and track their progress through an interactive user interface.

🎯 Objectives

- Organize daily tasks efficiently.
- Add and manage tasks easily.
- Keep track of pending and completed activities.
- Improve productivity and time management.
- Provide a simple and user-friendly interface.

🚀 Key Features

- Add Tasks: Create new tasks with ease.
- View Tasks: Display all added tasks.
- Delete Tasks: Remove tasks that are no longer required.
- Task Management: Manage daily activities in one place.
- Interactive UI: Simple and user-friendly interface.

🛠️ Technologies Used

- Python
- Streamlit
- Datetime Module

💻 Installation and Setup

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory:
   
   cd todo-list

3. Install Streamlit:
   
   pip install streamlit

4. Run the application:
   
   streamlit run app.py
